# Инструкция выполнения и доказательства

## Развёртывание локального стенда
1. Установите Docker Desktop/Engine и Compose.
2. Скопируйте lab/.env.example в lab/.env (либо задайте переменные в корневом .env) и замените локальные пароли.
3. Запустите docker compose -f lab/docker-compose.yml up -d.
4. Откройте http://localhost:8080, завершите установку WordPress.
5. Выполните bash scripts/harden-and-audit.sh и bash scripts/http-security-test.sh.

## Содержание пунктов
- Корень: скрипт удаляет readme.html/license.txt и распространённые дампы в корне только внутри disposable lab.
- CHMOD: каталоги 755, файлы 644, wp-config.php 440.
- wp-config: корневой .htaccess запрещает HTTP-доступ к нему.
- uploads: локальный .htaccess блокирует PHP/PHTML/PHAR; тестовый скрипт удаляется trap-обработчиком.
- DISALLOW_FILE_EDIT: запрещает редакторы тем/плагинов в админке.
- WP_DEBUG: логирование включено, отображение посетителям выключено. После лабораторной работы отключите WP_DEBUG на публичном production-сайте.
- Перенос wp-config: после успешной установки можно переместить файл на уровень выше web-root, затем перепроверить фронтенд и wp-admin. Не выполняйте автоматически в контейнере без понимания bind mounts.
- table_prefix: для нового стенда можно использовать sec_lab_. Для существующего сайта изменение требует миграции БД и корректировки ссылок в options/usermeta.

## Ручная проверка переноса конфигурации
В контейнере путь web-root — /var/www/html, родитель — /var/www. Сначала резервная копия. Переместите wp-config.php в /var/www/wp-config.php, затем проверьте главную и /wp-admin. Возврат при ошибке: вернуть файл в /var/www/html/wp-config.php. Для скриншота показывайте дерево каталогов без содержимого файла и без секретов.

## Доказательства
Сохраните скриншоты: корень после очистки; свойства CHMOD; браузерный 403 для wp-config; 403 для временного PHP в uploads; wp-admin без редакторов; значения debug-констант (без секретов); дерево файлов с конфигом выше web-root; строка table_prefix (без паролей). Никогда не снимайте и не публикуйте секреты БД/salts.
