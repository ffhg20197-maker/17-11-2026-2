# Контрольный лист перед сдачей

Дата: 17.11.2026  
Тема 3.2.49: «Структура файлов WordPress, требующих защиты».

## Запуск лаборатории
```bash
cp lab/.env.example .env
# Заменить пароли в .env
docker compose -f lab/docker-compose.yml up -d
# Завершить установку WordPress на http://localhost:8080
bash scripts/harden-and-audit.sh
bash scripts/http-security-test.sh
bash scripts/move-config-outside-webroot.sh
```

## Критерии методички

| Пункт | Баллы | Что должно быть подтверждено |
|---|---:|---|
| 1.1 Очистка корня | 10 | Нет readme.html/license.txt и резервных .sql/.zip/.bak; снимок каталога |
| 1.2 CHMOD | 10 | Каталоги 755, файлы 644, wp-config.php 400/440; снимок прав |
| 1.3 Запрет wp-config | 10 | До переноса запрос возвращает 403; содержимое не раскрывается |
| 2.1 Запрет PHP в uploads | 15 | Временный test PHP получает 403 и удалён; снимок .htaccess и ответа |
| 2.2 DISALLOW_FILE_EDIT | 10 | Константа true; меню админки без редакторов тем/плагинов |
| 2.3 WP_DEBUG | 10 | WP_DEBUG=true, DISPLAY=false, LOG=true; журнал не доступен публично |
| 3.1 Вынос wp-config | 15 | Конфигурация находится на уровень выше web-root; сайт и wp-login работают |
| 3.2 table_prefix | 10 | Указан фактический префикс и объяснён риск стандартного wp_ |
| Отчёт | 10 | Титульный лист, скриншоты, листинги, выводы |
| **Итого** | **100** | Все критерии подтверждены преподавателю |

## Технические проверки
- До переноса: `curl -i http://localhost:8080/wp-config.php` — ожидается 403.
- Тест uploads выполняется скриптом и временный файл автоматически удаляется.
- После переноса: `curl -i http://localhost:8080/wp-config.php` — обычно 404, поскольку файл вынесен из DocumentRoot.
- Войти в /wp-admin и проверить отсутствие редакторов.
- В отчёт добавить собственные скриншоты, не макеты.

## Важные замечания
- Не публиковать настоящий wp-config.php, DB-пароли, salts, дампы и debug.log.
- Для существующей базы нельзя менять $table_prefix простой заменой строки: нужна миграция таблиц и связанных значений.
- WP_DEBUG после лабораторной работы отключить на production.
- Правила .htaccess применяются на Apache/LiteSpeed; Nginx требует эквивалентной конфигурации.
