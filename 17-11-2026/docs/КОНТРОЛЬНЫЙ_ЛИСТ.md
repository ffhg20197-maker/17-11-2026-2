Дата комплекта: 17.11.2026  
Задание: Тема 3.2.49 «Структура файлов WordPress, требующих защиты».

> Важно: репозиторий содержит подготовленные конфигурации, инструкции и инструменты. Он не подключён к учебному серверу WordPress. Пункты, зависящие от хостинга, отмечайте выполненными только после самостоятельной проверки.

## Команды проверки

```bash
stat -c '%a %U:%G %n' /path/to/wordpress/wp-config.php
find /path/to/wordpress -type d -printf '%m %p\\n' | head
find /path/to/wordpress -type f -printf '%m %p\\n' | head
curl -sS -o /dev/null -w '%{http_code}\\n' https://example.test/wp-config.php
curl -sS -o /dev/null -w '%{http_code}\\n' https://example.test/wp-content/uploads/test.php
php tools/audit.php /path/to/wordpress
```

## Перед публикацией

- Не добавлять настоящий wp-config.php, пароли, salts, дампы БД или приватные журналы.
- Не оставлять тестовый PHP-файл в uploads.
- После лабораторной диагностики выключить WP_DEBUG в production.
- Не менять префикс существующей базы простой заменой строки.
- На Nginx перенести запреты в конфигурацию Nginx: .htaccess там не применяется.
