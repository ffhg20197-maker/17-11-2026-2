Что реализовано

01 / FILESYSTEM

Права и очистка

Проверка каталогов 755, файлов 644, конфигурации 440. Удаление readme, license и типовых резервных файлов.

02 / CONFIG

Защита конфигурации

Запрет прямого HTTP-доступа к wp-config.php, отключение встроенного редактора тем и плагинов.

03 / UPLOADS

Безопасные загрузки

Запрет исполнения PHP в wp-content/uploads. Временный тестовый PHP-файл получает отказ в доступе.

04 / DATABASE

Настройки БД

Проверка нестандартного префикса таблиц sec_lab_ и параметров диагностического журнала.

05 / CONFIG MOVE

Перенос wp-config.php

Конфигурация вынесена за пределы DocumentRoot. После переноса проверяются главная страница и форма входа.

06 / AUTOMATION

Автоматические тесты

GitHub Actions поднимает временную WordPress + MariaDB среду, применяет настройки и выполняет проверки.

Как устроен проект

lab/

Docker Compose, пример локальных переменных окружения, правила Apache и фрагмент конфигурации WordPress.

scripts/

Скрипт hardening и аудита, HTTP smoke tests, безопасный перенос wp-config.php с откатом при ошибке.

.github/workflows/

Автоматизированный pipeline: установка CMS, применение мер защиты, проверки и сохранение тестовых результатов.

Важно о демонстрации. Это публичная информационная страница проекта и отчёт о результатах автоматизированной лабораторной проверки. Сам WordPress запускается во временном Docker-окружении GitHub Actions и не является постоянно работающим публичным сайтом или админ-панелью. CI-проверки не означают, что изменения применены к отдельному production-сайту.
